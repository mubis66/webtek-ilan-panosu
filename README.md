## Adımlar
(Bunları kendi cümlelerinle yeniden yaz, aşağıdakiler taslaktır.)

- **Adım 0:** GitHub'da depoyu açtım, Pages'i main dalından yayına aldım.
- **Adım 1:** header, nav, main (iki section) ve footer ile anlamsal iskeleti kurdum.
- **Adım 2:** Başvuru formunu yaptım. Doğrulamayı required, type ve pattern öznitelikleri yapıyor; form.js sayfa yenilenmeden mesaj gösteriyor.
- **Adım 3:** stil.css içinde --ton değişkeniyle ana rengi tanımladım.
- **Adım 4:** İlan kartlarını auto-fit/minmax ile duyarlı bir Grid'e dizdim.
- **Adım 5:** app.js ile ilanlar.json'u fetch ile okuyup kart ürettim; iki ilan ekledim.
- **Adım 6:** Alan seçimi ve arama kutusu birlikte çalışıyor.
- **Adım 7:** "Listeme ekle" düğmesi ilan id'lerini localStorage'daki basvuracaklarim anahtarına yazıyor.
- **Adım 8:** fetch kodunu veri.js modülüne taşıdım, app.js import ediyor.
